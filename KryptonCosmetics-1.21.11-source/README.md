# Krypton Cosmetics

Client-only cosmetic wardrobe for Minecraft Java 1.21.11, Fabric Loader 0.19.5, Java 21 and Yarn 1.21.11+build.6. It has four original cape palettes, four backpack looks, a centered character preview, persistent toggles and a compact HUD label. Open the config from this mod's entry in Mod Menu, or press Right Shift. The Mod Menu API integration is optional at runtime. No gameplay or network packets are changed; Krypton is optional and no Netty handlers are installed.

The included CC0 backpack sprite source is credited in `ASSETS.md`.
